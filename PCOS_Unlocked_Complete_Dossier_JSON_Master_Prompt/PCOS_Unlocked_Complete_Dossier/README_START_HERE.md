# PCOS Unlocked — Start Here

This ZIP contains a complete project dossier, structured JSON configuration files, a Google AI Studio master prompt and original SVG educational diagrams.

## Recommended workflow
1. Upload/extract the package in your Google AI Studio project context.
2. Read `00_COMPLETE_PROJECT_DOSSIER.md`.
3. Supply all JSON files and the `assets/` folder as build references.
4. Paste `01_GOOGLE_AI_STUDIO_MASTER_PROMPT.md` into Google AI Studio.
5. Ask the model to implement every route and verify every interaction.
6. Run the checks in `08_BUILD_AND_QA_CHECKLIST.json`.

This is a build specification and asset package, not a deployed or pre-tested website. Medical content needs qualified clinical review before public launch.

**Dataset note:** the two CSVs do not contain gender or awareness questions and cannot support male/female awareness comparisons.
